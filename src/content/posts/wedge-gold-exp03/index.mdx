## 为什么换到黄金

前两个实验一共回放了 63 笔，都在 MES 上。[实验 01](/posts/fixed-2r/) 是固定 2R。实验 02 是入场时按结构选目标，还没做完。

黄金一天交易 23 小时，[波动集中在美盘](/posts/gold-sessions/)。同一套 Wedge 搬过去还灵不灵，我不知道，所以做这个实验。

拿来对比的是实验 02 的 33 笔：到 1R 的占 61%，到 1.5R 的占 39%，到 2R 的占 27%。

## 规则

<div class="exp-table">

| 项目 | 做法 |
|:---|:---|
| 方法 | TradingView Replay 回放，MGC 5 分钟图 |
| 入场 | 只做强信号K，止损放在信号K外侧（= 1R） |
| 离场 | 到 1R 以后移不移保本，看当时的判断。实际怎么离场就怎么记 |
| 回放 | 选连续的交易日，每天从美东 18:00 按顺序走完，不跳时段 |
| 收盘 | 纽约 16:00 以后不开新仓，17:00 前平仓 |
| 样本 | 60 笔，主要比上海、欧洲、纽约三段 |

</div>

不跳时段是因为：只挑纽约时段回放的话，各时段出现多少次 Wedge 就没法比了。

## 一天分成五段

黄金没有统一的开盘。我按各地的开盘把一天切成五段，每段从 1 开始数 K 线。

<div class="exp-table">

| 时段 | 从什么时候起 |
|:---|:---|
| 亚洲早盘 | 纽约 18:00 |
| 上海 | 北京 09:00 |
| 欧洲 | 伦敦 08:00 |
| 纽约 | 纽约 09:30 |
| 纽约盘后 | 纽约 16:00 |

</div>

<p class="table-note">各段按当地时间起算，冬夏令时自动跟着走。</p>

每笔记两样：信号K在哪一段，是这一段的第几根。这两格按入场时间自动算，不用手填。

## 每笔手填什么

<div class="exp-table">

| 列 | 填什么 |
|:---|:---|
| Setup | wedge reversal 还是 wedge flag in trend，第一次还是第二次入场 |
| 信号K | strong 还是 weak，trend bar 还是 pin bar |
| 离场方式 | 1R、1.5R、2R、3R 止盈，保本离场，初始止损，移动止损，收盘平仓 |
| 最远到达 | 见下一节 |
| 回测成本价前到过 | 见下一节 |
| Initial Risk | 入场价到止损的点数 |
| 复盘小结 | 背景、形态、信号 |

</div>

入场K和 Actual Risk 这次不记，想让每笔要判断的东西少一点。

## 到 1R 以后要不要移保本

到 1R 以后，我有时候移保本，有时候不移，看当时的判断。哪种做法好，我一直没数过。

价格到 1R 以后回到成本价，后面有两种走法：

<div class="exp-table">

| 回到成本价以后 | 移了保本 | 没移 |
|:---|:---:|:---:|
| 继续走到目标 | 0 | 赚到目标 |
| 一路走到初始止损 | 0 | −1R |

</div>

该不该移，要数这两种各有多少，合起来差多少 R。

### 只记“是 / 否”不够

实验 01 里我记过“到 1R 后有没有回到成本价”，只填是或否。30 笔里到过 1R 的有 20 笔，其中 9 笔回到了成本价。那次目标只有 2R 一个，是或否够用。

这次想同时比 1.5R、2R、3R 三个目标，就不够了。看两笔单子，都是最远到 3R，都回到过成本价：

<div class="exp-table">

| 走法 | 移保本、目标 1.5R | 移保本、目标 2R |
|:---|:---:|:---:|
| 到 1R，回成本价，再到 3R | 0 | 0 |
| 到 2R，回成本价，再到 3R | +1.5R | +2R |

</div>

第二笔在回来之前已经止盈了。两笔在表里长得一样，结果差了 1.5R 到 2R。

### 现在每笔记两格

<div class="exp-table">

| 列 | 定义 |
|:---|:---|
| 最远到达 | 止损一直留在初始位置，打到初始止损或收盘之前，价格最远走到几 R |
| 回测成本价前到过 | 到 1R 以后，第一次回到成本价之前，最远到过几 R。到 3R 之前没回来过，填 3R |

</div>

上面那两笔，最远到达都填 3R。第二格一笔填 1R，一笔填 2R，就分开了。

有了这两格，随便定一个目标，两种做法的结果都能算：

<div class="exp-table">

| 做法 | 怎么算 |
|:---|:---|
| 不移 | 最远到达够目标，赚到目标。不够，亏 1R |
| 移保本 | 回成本价之前到过目标，赚到目标。到过 1R 但没到目标，记 0。没到 1R，亏 1R |

</div>

### 七种走法对一遍

这个记法对不对，我把能想到的走法都列出来算了一遍。

<div class="exp-table">

| 走法 | 最远到达 | 回测前到过 | 移保本<br/>1.5R / 2R / 3R | 不移<br/>1.5R / 2R / 3R |
|:---|:---:|:---:|:---:|:---:|
| 直接到 3R | 3R | 3R | +1.5 / +2 / +3 | +1.5 / +2 / +3 |
| 到 1R，回成本价，再到 3R | 3R | 1R | 0 / 0 / 0 | +1.5 / +2 / +3 |
| 到 2R，回成本价，再到 3R | 3R | 2R | +1.5 / +2 / 0 | +1.5 / +2 / +3 |
| 到 1.5R，回成本价，到 2R，止损 | 2R | 1.5R | +1.5 / 0 / 0 | +1.5 / +2 / −1 |
| 到 1R，回成本价，到 1.5R，止损 | 1.5R | 1R | 0 / 0 / 0 | +1.5 / −1 / −1 |
| 到 1R，回成本价，止损 | 1R | 1R | 0 / 0 / 0 | −1 / −1 / −1 |
| 直接止损 | 未到 1R | 未到 1R（自动） | −1 / −1 / −1 | −1 / −1 / −1 |

</div>

<p class="table-note">单位是 R。目标 1R 时两种做法结果一样，没列。</p>

七种都对得上。

### 最容易填错的地方

最远到达要一直看到打初始止损或收盘。我自己离场以后，图还得接着往后放。

只填到自己离场的位置，后面的对比就全错了。这一条我估计自己会偷懒，先写在这里。

## 现在就知道的问题

样本会很薄。移不移只在“到过 1R 又回到成本价”的单子上有差别，60 笔里只有一部分是这种，再按时段分就更少了。

所以移保本这个问题只看整体，不分时段。
